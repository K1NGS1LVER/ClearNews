# Notes for teaching ClearNews

Scratchpad for the teacher. Capture user preferences, working notes, and anything that should influence how lessons are designed.

## User preferences observed

- User wants plain-language explanations, not just code walkthroughs.
- User is interested in the "why" behind each decision — pros and cons, trade-offs.
- User asked specifically about architectural decisions and their rationale.

## Working notes

- First lesson (0001-project-architecture.html) covers the overall flow and eight major decisions.
- Next lessons could drill into: NLP pipeline, clustering details, agent/citation design, feed ranking formula, deployment story.
- The project README.md is the canonical source for run instructions and stack details.
